# SmartKruzhok 2.0

Telegram-бот по ТЗ 0.2. Короткие видео превращаются в нативные кружки с автоматическим кадрированием. Видео длиннее минуты можно разделить на серию. Под результатом доступны переделка кадра, русские автосубтитры, надписи, VHS и зум на лицо.

- «Выбрать фрагмент» принимает диапазон вроде `0:25–0:53` и собирает один кружок.
- «С субтитрами» выдаёт версию с текстом сразу. В меню оформления можно править строки и выбрать расположение субтитров сверху, снизу или автоматически.
- В оформлении можно вместе использовать надпись, субтитры, ретроэффект и зум. Надпись и субтитры накладываются поверх выбранного кадра. Из предпросмотра можно вернуться к настройкам или сделать кружок.
- В меню «Эффекты» можно добавить цветную рамку, плёночное зерно и до трёх эмодзи сверху и снизу. Эмодзи можно выбрать из набора или ввести с клавиатуры. Они видны весь кружок. Для перехода в чёрно-белое можно выбрать секунду от начала фрагмента или серии.
- В меню кадрирования «Выбрать лицо» показывает стоп-кадр с номерами. Бот следует за выбранным человеком, пока может уверенно его отслеживать.
- При разбиении серии бот ищет тихую паузу в звуке за несколько секунд до границы. Если паузы нет, часть длится до 60 секунд.
- Сообщение о ходе обработки обновляется по мере работы. Кнопка «Отменить» снимает задание из очереди или останавливает его после текущего этапа.
- `/menu` открывает кнопки «Новое видео», «Статус» и «Начать заново». Сброс закрывает незавершённый ввод и отменяет активное задание. После завершения можно прислать следующее видео прямо в чат или нажать «Новое видео» под результатом.

Telegram показывает приветствие в пустом чате до нажатия Start. Для другого бота текст можно задать командой `/setdescription` в @BotFather, а [обложку](assets/welcome.jpg) загрузить через `/setdescriptionpic`. Эти настройки привязаны к боту и сохраняются при переносе на другой сервер с тем же токеном.

## Запуск через Docker

1. Создайте тестового бота командой `/newbot` в [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`. Храните токен только в локальном файле или в переменных окружения сервера.
3. Из корня проекта запустите:

   ```sh
   docker compose up --build -d
   docker compose logs -f bot
   ```

4. Откройте своего бота в Telegram, отправьте `/start` и загрузите MP4, MOV или WebM до 20 МБ и 3 минут.

При первом запросе субтитров бот скачает модель Faster Whisper `base` в постоянный том. Модель можно загрузить заранее после запуска контейнера:

```sh
docker compose exec bot python -c 'import os; from faster_whisper import WhisperModel; WhisperModel(os.getenv("WHISPER_MODEL", "base"), device="cpu", compute_type="int8", download_root="/data/models")'
```

## Тестовый запуск в Northflank Sandbox

1. Создайте один сервис в бесплатном проекте Sandbox. Панель Northflank может потребовать карту для проверки аккаунта перед созданием ресурсов. Соберите сервис из `Dockerfile` в закрытом репозитории или импортируйте заранее собранный образ. Для первого теста проверьте, доступен ли размер 0,5 vCPU и 1 ГБ RAM в бесплатной квоте проекта. [Правила верификации Northflank](https://northflank.com/docs/v1/application/billing/pricing-on-northflank), [сборка из репозитория](https://northflank.com/docs/v1/application/getting-started/build-and-deploy-your-code), [импорт образа](https://northflank.com/docs/v1/application/build/import-container-images).
2. Выберите одну реплику без публичного порта. Бот сам подключается к Telegram по HTTPS. Добавьте `BOT_TOKEN` как секрет времени выполнения. Хранилище `/data` содержит SQLite, временные видео и кэш Whisper. Если используется временное хранилище, при замене контейнера придётся снова загрузить модель, а текущие черновики и очередь пропадут.
3. Дождитесь завершения сборки. Перед включением облачной реплики остановите локальный процесс, чтобы один токен использовал один процесс получения сообщений. После запуска проверьте в Telegram `/start`, создание кружка из короткого MP4 и кнопку «С субтитрами». Если облачный экземпляр не запускается, остановите его и возобновите локальный процесс.

## Локальный запуск на macOS или Linux

Понадобятся Python 3.11 и FFmpeg с `ffprobe` и `libx264`. На Linux установите Noto Color Emoji и DejaVu Sans Bold. Путь к другому шрифту с кириллицей можно указать в `FONT_PATH`.

```sh
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
mkdir -p models
curl -fL https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx -o models/yunet.onnx
set -a
. ./.env
set +a
FACE_MODEL="$PWD/models/yunet.onnx" .venv/bin/python -m smartkruzhok
```

В Docker модель YuNet устанавливается при сборке. При локальном запуске без `FACE_MODEL` используется детектор лиц OpenCV Haar.

Очередь и временные данные находятся в `DATA_DIR` (локально `./data`, в Docker `/data`). Запускайте один экземпляр на каталог данных. После выдачи результата исходник доступен для редактирования 30 минут, затем фоновая уборка его удаляет. В журналах сохраняются этапы обработки, время ожидания и коды ошибок.

Для проверки в Telegram загрузите короткое видео с движущимся лицом, ролик без звука и ролик на 61 секунду. У короткого видео попробуйте сменить кадр, добавить русские субтитры и надпись, посмотреть эффект и отправить оформленный кружок. Длинное видео должно вернуться двумя кружками в порядке воспроизведения.
